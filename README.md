# CatchUp

A Windows desktop app for K-pop fans: every variety show, MV, stage and appearance from the groups you follow, a
built-in player that remembers what you've watched, news and comeback countdowns, and Encore Awards (rate songs, tier
lists and an awards night with a friend).

## Install

Download `CatchUp_<version>_x64-setup.exe` from the [latest release](../../releases/latest) and run it. It installs
for your Windows account only (no admin needed). The installer isn't code-signed, so Windows SmartScreen may say
"Windows protected your PC" the first time: choose **More info → Run anyway**.

You can also install and update it from FrozenKingdom.

## Updates

CatchUp checks this page for new versions and **asks before downloading** anything. Your data (watch history, ratings,
settings and your own YouTube key, if you add one) stays on your PC and is never part of an update.

## YouTube key (optional)

CatchUp works without one. Adding your own free YouTube Data API key in Settings finds much more content. Each person
uses their own key; it's stored encrypted on your PC and is never shared or uploaded.
